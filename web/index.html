Download rules

下载说明

解析顺序

先查开放获取：arXiv → OpenAlex → Unpaywall → Europe PMC → PMC → 出版社落地页；Sci-Hub 默认优先尝试（可在下方关闭），请自行判断所在地区的法律。

没有 OA 版本时

若关闭 Sci-Hub 兜底，该行标为「无开放获取」，可以点行内链接在浏览器打开出版社页面。

Sci-Hub 镜像（每行一个）
按顺序尝试，失败率高的镜像会自动排到后面。ALTCHA 验证码（工作量证明）会自动求解；图片验证码无法处理，会标记为需人工。
机构订阅（校园网 / 图书馆）

在校园网里通常不用登录：出版社按学校 IP 直接放行，勾上下面第一项即可。只有在校外、或需要 EZproxy/SSO 时，才先在这里登录一次（程序不接触你的密码）。

尚未检测
机构通道是串行的，每篇间隔 3 秒。批量下载会触发出版社的"系统性下载"判定——Elsevier 曾因此封禁整所大学的 EZproxy 一整天。几百篇的批量请分批跑。
出版社 API 密钥（可选，但能省掉大量失败）

ScienceDirect 这类站点前面有 Cloudflare 人机验证，浏览器自动化过不去，只能点。走出版社自己的 API 就没这道门，但需要一次性申请。

密钥只存在本机 settings.json，不会上传。你申请到的 key 通常绑定所在机构的订阅——不要分享给他人，也不要打包进安装包；每位使用者应各自申请。付费且没有 API 授权的文章，本软件不做承诺。
命名模板
可用占位符：{first_author} {year} {title} {journal} {doi}
并发下载
多条同时下载；Sci-Hub 的 ALTCHA 是串行求解，并发过高反而更容易被拦。
文件去哪了

保存在上面的「下载目录」；同目录的 .doi-index.json 记录已下载的 DOI，重复运行会自动跳过。
