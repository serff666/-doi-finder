# DOI Finder

**从一串论文标题，到本地整理好的 PDF 文献库。**
在自己电脑上运行的文献检索与批量下载工具：把标题（或整条参考文献）解析成 DOI，再按出版社自动选路线，把 PDF 下到本地并规范命名。

界面在浏览器里（`http://127.0.0.1:8765/`），不需要账号、不需要注册，数据和密钥都只留在你的电脑上。
Windows 桌面应用，也可在 Linux 上从源码运行（见 [README.linux.md](README.linux.md)）。

> English: see [README.en.md](README.en.md).

## 它解决什么问题

手上有几十、几百篇论文的标题，或者一份参考文献列表，想把全文都拿到：

1. 逐篇去搜 DOI，容易搜错、搜不到；
2. 逐篇去各家出版社页面找 PDF，有的开放获取、有的要机构订阅、有的卡在验证码；
3. 下完文件名一团糟，哪篇下过哪篇没下过记不清。

DOI Finder 把这三步串成一条流水线，并且**每一步都告诉你结果有多可信、没成功的原因是什么**。

## 核心能力

**① 标题找 DOI，找得准，也说得清**
- 不是取搜索结果第一条：用标题相似度、第一作者、年份、期刊、卷期页互相印证，分「高可信 / 可能匹配 / 需核对 / 未找到」四档，每条写明依据。
- 一行一条标题、整条参考文献、带序号的列表、BibTeX、RIS 都能直接粘；行尾带 `doi:` 的直接采用。
- Crossref 为主、OpenAlex 兜底；同标题的预印本与正式版按年份区分；中文文献可用百度学术链接补 DOI。
- 可导出 Excel / Markdown / HTML / CSV / DOI 清单，以及 **GB/T 7714、ACS、APA** 参考文献。

**② 下得到：多渠道、按出版社选路线**
- 按 DOI 前缀和发表年份决定顺序：Elsevier / Wiley 走官方 API，ACS / RSC 等订阅刊走机构浏览器，开放出版社直接取，预印本有预印本的走法。
- 开放获取一步并行查 OpenAlex、Unpaywall、Europe PMC、Semantic Scholar、PMC、OSTI、Zenodo、HAL、Crossref、DOAJ、CORE、Internet Archive Scholar，谁先给出有效 PDF 用谁。
- Sci-Hub / Sci-Net 兜底（可关）：镜像按成功率自动排序，ALTCHA 验证自动求解。
- **机构浏览器永远会试**：用你本机 Chrome/Edge 的校园网或 CARSI 登录会话取 PDF；程序不碰你的密码，也不会因为“猜你没订阅”就跳过它（文章可能是开放获取）。
- **预印本兜底**：正式版下不到时，去 ChemRxiv 找同一篇——标题、DOI 都可能和正式版不一样，程序用期刊记录里登记的关联、标题、第一作者、年份来对，并写明每条是怎么对上的。2025 年及以后的新文献（开放获取库往往还没收录），在打开机构浏览器之前就先用「期刊记录明确登记的」预印本。
- SSRN、Research Square 这类预印本 DOI，会回 Crossref 找到正式发表版并改下那一版。

**③ 批量下得稳**
- 断点续传、按 DOI 去重（同目录 `.doi-index.json`），重跑自动跳过；下载后校验 PDF 完整，半截文件会重下。
- 暂停 / 继续 / 停止；失败的可以只重试没完成的；「只看未获取」，一键导出未获取清单（CSV）。
- 每条结果写明**实际下载渠道**和失败原因（无开放获取 / 需订阅 / 验证码 / 超时），不是一句“失败”。
- 命名模板 `{first_author}_{year}_{title}`，可加 `{journal}` `{doi}`；长标题、中文、Windows 保留名都处理。

**④ 找文献的多个入口，都能直接下载**
- **主题搜索**：关键词 / 作者 / ORCID / 年份，可只看开放获取。
- **ChemASAP**：化学各方向期刊最新的 ASAP（提前在线）文章，不限于有机，也包含 ChemRxiv 预印本。
- **期刊追新**：盯几本刊，标出上次之后新出的、没读过的。
- **期刊文库**：整本期刊从创刊到今天的全部文章（Crossref 书目），按「刊名/年份/Volume 卷, Issue 期」文件夹批量下载；可显示审稿周期、分区（可选数据集）。
- **网页文献**：粘贴任何课题组 publications 页面，用真实浏览器抓出所有论文的标题、DOI、PDF 直链。
- **ResearchGate**：抓某位作者的论文清单。
- **预印本**：专门页面查找 ChemRxiv 预印本，核对后在本页下载。
- **归档**：从别处拿到的 PDF，按同一套规范重命名入库。

**⑤ 每个页面各管各的**
每个页面在自己页面里下载，有自己的进度面板（进度条、暂停、停止、重试、打开下载目录），也有自己的**工作区、放进哪个文件夹、怎么分层、Sci-Hub 开关、机构浏览器开关、并发数**。文件按统一的「工作区 / 作者或期刊名 / 年份 /」规则自动放好（见下面「文件怎么存」）。一边下某个期刊，一边下某个课题组的文章，互不干扰。

**⑥ 本地、透明、可控**
- 在自己电脑上运行，无账号；密钥（Elsevier、Wiley、CORE、OpenAlex）只存本机 `settings.json`，不上传、不打包。
- 中英文界面切换；每个渠道都能单独开关；证书校验默认开启。

## 一分钟上手

1. 启动程序，浏览器里打开 `http://127.0.0.1:8765/`；顶部选一个「工作区」（例如 `D:\文献`），设置里填「联系邮箱」（可选，但能少被限流）。
2. 在 **① 标题 → DOI** 粘贴标题，点「开始批量检索」，扫一眼状态（高可信 / 可能匹配 / 需核对）。
3. 点「→ 下载这些 PDF」，在本页看进度；下不到的点「找预印本版本」或「重试」。
4. 导出未获取清单，或点「打开下载目录」看文件——它们已按「工作区 / 作者或期刊名 / 年份」放好。

## 页面一览

| 页面 | 输入 | 输出 |
|---|---|---|
| ① 标题 → DOI | 一串标题或整条参考文献 | 每条对应的 DOI（附可信度和依据），可导出表格和参考文献 |
| ② DOI → PDF | 一串 DOI | 本地 PDF 文件，命名规范，可断点 |
| ③ 主题搜索 | 关键词、作者、ORCID、年份 | 相关文献列表，勾选后在本页下载 |
| ④ ChemASAP | 无 | 化学各方向期刊的最新 ASAP 文章 |
| ⑤ 期刊追新 | 期刊名或 ISSN | 该刊最近发表，标出未读 |
| ⑥ ResearchGate | 作者主页链接 | 该作者的论文清单（需已登录） |
| ⑦ 归档 | 本地 PDF 文件 | 按规范重命名并入库 |
| ⑧ 网页文献 | 课题组 publications 页地址 | 页面上所有论文的标题、DOI、PDF |
| ⑨ 期刊文库 | 期刊名或 ISSN（可限年份） | 整本期刊的文章清单，按「刊/年/卷期」文件夹批量下载 |
| ⑩ 预印本 | 标题或期刊版 DOI | ChemRxiv 上对应的预印本（标题、DOI 可以和正式版不同），勾选后在本页下载 |

核心流程是三段：**标题 → DOI → PDF**，每一段的中间数据留在同一张表里，不用二次录入。

## 文件怎么存：工作区规则

所有页面用同一套规则，路径永远是：

```
工作区 / 文件夹 / 分层 / 文件.pdf
例：D:\文献\Zhang Xinglong\2025\Zhang_2025_Title.pdf
```

- **工作区**：你选一次的根目录（顶部「工作区」，例如 `D:\文献`）。所有文献都在它下面，不会散落在各处。
- **文件夹**：第一层，按「你在收集什么」自动命名，可在页面里改名：

| 页面 | 自动建议的文件夹 | 里面怎么分 |
|---|---|---|
| ③ 主题搜索（填了作者） | 作者名 | 按年份 |
| ③ 主题搜索（只有关键词） | 关键词 | 不分层 |
| ⑥ ResearchGate | 该作者的名字 | 按年份 |
| ⑤ 期刊追新 | 期刊名 | 按年份 |
| ⑨ 期刊文库 | 期刊名 | 年份 → `Volume V, Issue I` |
| ⑧ 网页文献 | 课题组网站域名 | 按年份 |
| ④ ChemASAP | `ChemASAP` | 按期刊 |
| ⑩ 预印本 | `预印本` | 不分层 |
| ① 标题 → DOI、② DOI → PDF | `未分类` | 不分层 |

- **里面怎么分**可选：不分层 / 按年份 / 按期刊 / 按期刊 → 年份 / 按年份 → 卷期；默认「自动」跟随上表。年份、期刊取自文献元数据，缺失时放进「年份未知」「期刊未知」，不会丢文件。
- 每个页面的下载设置行都会显示「将保存到：…」的完整路径，下载前能看清文件会放哪儿。
- **不重复下载**：工作区根目录的 `.doi-index.json` 记录所有已下载的文献。同一篇文章已在别的文件夹里（比如先按期刊下过，现在又按作者收集），会直接复制过来，不再联网下载；旧版本留下的各卷期索引也会自动识别。
- 页面里还可以给这一页单独指定另一个工作区；留空就用顶部的。

## 安装与启动

**已安装版**：桌面 `DOI Finder` 快捷方式，或 `%LOCALAPPDATA%\Programs\DOI Finder\DOI Finder.exe`。
程序启动后在浏览器里打开 `http://127.0.0.1:8765/`，右上角「退出」关闭服务。

> 应用无数字签名，Windows 可能提示「仍要运行」。

**源码运行**：

```bat
cd doi-finder
python server.py            :: 启动服务并打开浏览器
python server.py --port 9000
```

依赖：Python 3.11+。导出 Excel 需要 `openpyxl`；从 PDF 取文字需要 `pypdf`。
浏览器通道需要本机装有 Chrome 或 Edge。

## 第一次启动要填什么

| 位置 | 填什么 | 为什么 |
|---|---|---|
| 顶部「工作区」 | 任意文件夹，例如 `D:\文献` | 所有文献的根目录，下载会自动放进它下面的「作者名 / 期刊名 / 课题组…」文件夹（规则见上面「文件怎么存」）。不填会用系统默认目录 |
| 设置里的「联系邮箱」 | 你自己的邮箱 | 发给 Crossref / Unpaywall / OpenAlex 的请求会带这个地址，进入它们的「礼貌池」，配额更高。**不填也能用，但更容易被限流（429）** |
| 设置里的「命名模板」 | 默认 `{first_author}_{year}_{title}` | 文件名格式，可用 `{journal}` `{doi}` |

填完点「保存」。其余设置都能后改。

**不需要账号，不需要注册。** 少数字段（机构通道、出版社 API）是可选的，见各自页面说明。

## 页面说明

### ① 标题 → DOI

**用途**：手上只有标题列表（或整条参考文献）时，找出每条的 DOI。

**怎么填**：

- 一行一条，序号可带可不带：`1.` `2)` `(3)` `[4]` `#5` 都会被剥掉
- 整条参考文献也行：`Spies JA, et al. Chem Soc Rev. 2019;48:1865-1873.`
- 也接受 BibTeX 与 RIS（从 Zotero / EndNote 导出的记录整段粘贴即可）。其中的年份、第一作者、期刊会一起核对：年份相差 2 年以上、或第一作者与记录里的所有作者都对不上，状态降一级并在备注里写明；缺字段不扣分。年份和第一作者都吻合、标题相似度在 0.70 以上的「不确定」，升为「很可能」。同标题的预印本与正式版，会按年份挑出对的那个，另一个留在备选里
- 行尾带 `doi: 10.xxxx/...` 的，会直接采用那个 DOI，不再查询

**两个开关**：

- **Crossref 不足时用 OpenAlex 兜底**：Crossref 查不到再问 OpenAlex。关掉更快，但漏检更多
- **相同标题只查询一次**：重复标题自动合并

**结果状态**：

| 状态 | 含义 | 建议 |
|---|---|---|
| 高可信 | 标题高度一致，且证据互相印证 | 直接用 |
| 可能匹配 | 标题像，但证据不足 | 扫一眼 DOI 链接 |
| 需核对 | 匹配上了，但字段对不上 | 点「修改」手动确认 |
| 未找到 | 没有可用候选 | 点「修改」手填，或去 ③ 主题搜索 |

**每行可以做的**：点 DOI 打开原文；点「修改」可手填 DOI 或从候选里挑；导出 Excel / Markdown / HTML / CSV / DOI 清单 / 参考文献。

**参考文献导出**：右上角选格式，支持 **GB/T 7714、ACS、APA** 三种。作者、卷、期、页码取自 Crossref 元数据，缺的字段留空，不猜。

**中文文献**：知网/万方收录的论文在 Crossref 里常常没有 DOI。把百度学术的论文链接（`xueshu.baidu.com/...paperid=...`）粘进右侧「百度学术链接 → DOI」，程序会取回标题、DOI、期刊、卷期页。

### ② DOI → PDF

**用途**：把 DOI 批量下成本地 PDF。

**怎么填**：一行一个 DOI，`https://doi.org/10.xxxx/...` 也认；可从 ① ③ ④ ⑤ 带入，或导入 TXT / CSV。

**右侧设置逐项说明**（这些是全局默认；每个页面的「本页下载设置」可以单独改工作区、文件夹、分层、Sci-Hub、机构浏览器、并发数）：

| 设置 | 说明 |
|---|---|
| 工作区 | 文献的根目录；② 页的文件放进它下面的「未分类」（可在 ② 页右侧改文件夹名和分层）。同名文件自动加序号，除非勾「重新下载」 |
| 并发 | 同时下几篇，默认 3，最快 5。开太多会被出版社限流 |
| 使用 Sci-Hub / Sci-Net 兜底 | **默认开启并优先尝试**，可在下载页关闭；请自行判断所在地区的合法性 |
| 跳过 Sci-Hub 镜像证书校验 | 默认关闭（即默认校验证书）；只有镜像证书过期、连不上时才勾选，且只应在可信网络下使用 |
| 机构浏览器兜底 | 用本机浏览器 + 你的校园网会话取 PDF。见下方「机构通道」 |
| Elsevier API key | dev.elsevier.com 免费申请。填了才能用 Elsevier 官方接口 |
| Elsevier insttoken | 订阅全文需要，向图书馆索取；开放获取文章不需要 |
| Wiley TDM token | 授权后免费，用于 Wiley 官方接口 |

**结果状态**：已下载 / 已存在 / 无开放获取 / 需订阅（验证码）/ 失败，每条都注明实际来源（OpenAlex、Europe PMC、Sci-Hub、机构通道…）。

**按钮**：浏览器打开（在浏览器里手动看）、机构登录（打开出版社页登录一次）、归档（本地已有 PDF 时手动入库）、重新归档、删除（只从列表移除，不删文件）。勾「只看未获取」可筛出没下到的。

**断点与去重**：同目录 `.doi-index.json` 记录已下载的 DOI，重跑自动跳过。勾「重新下载」强制覆盖。

**机构通道**：勾上「机构浏览器兜底」后，程序用本机 Chrome/Edge 打开出版社页面取 PDF。
第一次用需要点某行的「机构登录」，在弹出的窗口里登录一次（学校账号、CARSI、双因子都行），会话存在 `%LOCALAPPDATA%\DOIFinder\browser-profile*`，之后复用。
登录过期就再点一次「机构登录」。

### ③ 主题搜索

**怎么填**：主题关键词必填；作者、ORCID、起止年份可选；勾「仅开放获取」只看 OA。

**用法**：搜索 → 结果表勾选 →「选中项加入下载」，在本页下方出现进度面板直接下载。
点标题可看摘要。结果里的「来源」会告诉你数据从 Crossref 还是 OpenAlex 来。

---

### ④ ChemASAP

**用途**：拉取化学各方向期刊最新的 ASAP（提前在线发表）文章。

没有输入，点「刷新」即可。数据来自公开的 ChemASAP 接口，该服务收录约 125 个来源：有机、无机与催化、物理与分析、化学生物、药物化学、材料与高分子、综合与综述期刊，以及 ChemRxiv 最新预印本。本页目前显示服务返回的最新文章，可按标题、作者、期刊名筛选，或只看 OA；还没有按期刊或学科勾选的控件。勾选文章后在本页下载。

---

### ⑤ 期刊追新

**用途**：盯几本刊，看最新文章，标出哪些没读过。

**怎么填**：输入期刊名或 ISSN（如 `0021-9606` 或 `Journal of Chemical Physics`）→「查找」；或点「载入常用期刊」一次加一批。

**结果表**：「新」标记表示上次刷新之后新出现的。勾「只看未读」只看这些；「标记已读」把当前进度存下来。
勾选后「选中项加入下载」，在本页下载。

**说明**：数据来自 Crossref 的期刊目录，不经过出版社网页，所以没有验证码。

---

### ⑥ ResearchGate

**用途**：抓某个作者在 ResearchGate 上的论文清单。很多文献在那里是作者自己上传的全文。

**怎么填**：作者主页链接，例如 `https://www.researchgate.net/profile/Some-Name`。

**必须先用「打开并登录」**：ResearchGate 有 Cloudflare 人机验证，得在弹出的窗口里过一次。
登录后点「抓取论文列表」，程序会逐页翻，几百篇要一两分钟。

抓到之后：「全选」→「解析 DOI 并加入下载」，在本页下载。
抓到的条目可能没有 DOI，那就走标题解析。

---

### ⑦ 归档

**用途**：论文是从别处（知网、同事、作者主页）拿到的 PDF，想让文件名和目录符合规范。

**怎么填**：选择本地 PDF，程序读取首页文字猜标题，也可手动填标题、作者、年份、期刊、DOI。
填好后点归档，文件按模板改名并复制进下载目录。

### ⑧ 网页文献

**用途**：任何课题组的 publications 页面，一次抓出全部论文的标题、DOI、PDF 直链。

**怎么填**：粘贴页面地址，例如 `https://web.mit.edu/group/publications.html`。

**抓取**：用真实浏览器打开并逐轮加载（有的页面要滚到底或点「加载更多」），可能需要一两分钟。

**抓完怎么用**：

| 情况 | 处理 |
|---|---|
| 页面给了 PDF 直链 | 「下载选中」直接从那个链接下 |
| 只有 DOI | 在本页下方面板下载，走机构/API/开放获取 |
| 只有标题 | 填进 ① 去解析 |

按钮「下载选中（PDF 直链 / DOI 分流）」会一次把三类都处理掉，并告诉你怎么分的。
arXiv 预印本没有 DOI 时，程序会用 `10.48550/arXiv.<编号>` 合成。

**存放**：按统一规则放进「工作区 / 课题组网站域名 / 年份 /」，文件名带标题和链接哈希，防止重名覆盖。

### ⑨ 期刊文库

**用途**：把一本期刊从创刊到今天的全部文章列出来，批量下载并按「刊名 / 年份 / Volume 卷, Issue 期」分文件夹存放。

**怎么填**：期刊名（会给出 Crossref 建议，选中后自动填 ISSN）或直接填 ISSN；起止年份留空就是全部。「类型」决定默认勾选：全部 / 仅研究论文 / 仅综述 / 排除更正、社论、目录（默认）。

**步骤**：「抓取书目」（可停止）→ 在列表里勾选 →「下载选中（按刊/年/卷期）」。本页下方有进度面板，可暂停、停止、重试没完成的、打开下载目录；「下载明细」默认只列没获取的，可导出清单。

**说明**：书目来自 Crossref，目录页、封面、勘误会被过滤。从 ② 粘贴 DOI 下载的文件不分卷期文件夹，直接平铺。

### ⑩ 预印本

**用途**：正式期刊下不到，但作者往往把同一篇文章放在 ChemRxiv 上；预印本的**标题和 DOI 常和正式版不同**，所以不能按 DOI 直接对。

**怎么填**：每行一个论文标题或期刊版 DOI，点「查找预印本」。程序依次查：期刊记录里登记的预印本链接（Crossref 的 `has-preprint` 关系）→ ChemRxiv 官方搜索 → Crossref 里 ChemRxiv 的记录（前缀 10.26434），再用标题相似度、第一作者、年份打分。

**结果怎么看**：每个候选标明「有把握」或「待核对」并写出原因；只默认勾选有把握的。「查询失败」表示没问到，**不等于没有预印本**，用「重试」再查。预印本可能和正式版内容有出入，请自己核对。

**2025 年及以后的新文献**：开放获取库往往还没收录，程序会在机构浏览器之前先试 ChemRxiv 预印本，但只用期刊记录明确登记了的那一篇（确定匹配）；靠相似度猜的匹配仍然只作最后兜底。下到的预印本会在说明里标明“可能与正式版有出入”。设置里和每页的「新文献先预印本」可以关闭。

**下载失败时自动兜底**：各页面下载某篇所有途径都失败后，程序会最后试一次预印本，只采用有把握的匹配，并在说明里写出来；② 页「找预印本版本」按钮则把这些 DOI 送到本页由你核对。

## 期刊信息（可选）

「⑨ 期刊文库」页可以显示一本期刊的平均 / 中位审稿周期、JCR 分区、中科院分区和影响因子。数据来自公开数据集 [CrushSCI-Journal-Review-Time](https://github.com/wangshunqi2020-commits/CrushSCI-Journal-Review-Time)（CC BY-NC 4.0：仅限非商业使用，需署名）。**本项目不内置这份数据**，点「下载期刊数据」后只保存在你自己的电脑上。审稿天数是收稿到录用的日历天数，只是观察到的样本，不代表保证周期。

## 下载顺序是怎么定的

不是所有文献都走同一条路。程序按 DOI 前缀判断出版社，再看年份和你开了哪些通道：

| 文献类型 | 顺序 |
|---|---|
| 任何文献（开启 Sci-Hub 时） | **先试 Sci-Hub**，失败再走下面各行 |
| ACS、RSC、Science、AIP 等订阅刊 | 机构浏览器 → 直连 → 开放获取 → PMC |
| Wiley（10.1002） | Wiley API → 直连 → 开放获取 → PMC |
| Elsevier（10.1016） | Elsevier API → 直连 → 机构浏览器 → 开放获取 → PMC |
| MDPI、PLOS、Frontiers 等全开放出版社 | 直连 → 开放获取 → PMC |
| 预印本（arXiv、SSRN、ChemRxiv） | 直连 → 开放获取 → 机构浏览器 |

**开放获取那一步**会并行查 OpenAlex、Unpaywall、Europe PMC、Semantic Scholar、PMC、OSTI、Zenodo、HAL、Crossref、DOAJ、CORE（需免费 API key，可选）和 Internet Archive Scholar，15 秒内回来多少用多少；结果按 24 小时缓存，同一批重跑不再重复查询。

**预印本自动换正式版**：遇到 SSRN、Research Square 这类预印本 DOI，程序会用标题回 Crossref 找正式发表版本，找到就改下那一版（正式版常常是开放获取）。

## 常见问题

**查不到 DOI / 大量「失败」**
多半是被限流。确认「联系邮箱」已填；在 ① 里把并发调低；分批跑（一次几十条比一次几百条稳）。

**下不到，但我知道学校有订阅**（即使程序以为你没订阅也会照样打开机构浏览器：期刊可能是开放获取，打开就能下）
先点那一行的「机构登录」，在弹出窗口登录一次，再重下。若仍失败，看日志里那条的说明——「网络慢」和「没有订阅」是两回事，前者重试即可。

**PDF 打开是空白页**
旧版本会存下半截文件。现在下载后会校验文件结尾标记，不完整会重下；如果仍遇到，删掉那个文件重下。

**一直卡在某一篇**
浏览器通道单篇最长约两分半（75 秒 + 加倍重试）。可以先「暂停」，处理完别的再「继续」。

**日志在哪**
`%LOCALAPPDATA%\DOIFinder\doifinder.log`。每次下载结束会逐条记录没下到的文献和原因（`miss` 开头的行），排错看这个。

**界面点按钮没反应**
右上角状态栏会显示脚本错误和行号。刷新（Ctrl+F5）多半能解决。

## 密钥与隐私

- 所有密钥（Elsevier、Wiley、Unpaywall 邮箱）**只存在本机** `%LOCALAPPDATA%\DOIFinder\settings.json`，不上传、不打包进安装包
- 本仓库不含任何密钥；`settings.example.json` 里字段都是空的
- 请遵守各出版社的 API 条款：Elsevier API key 与 Wiley TDM token 是发给个人账号的，**不能共享**
- Sci-Hub 默认开启并优先尝试，可关闭。它是否合法取决于你所在地区，请自行判断
- 「机构通道」用的是你自己的浏览器会话，程序不保存密码

```

  server.py          本地 HTTP 服务、任务调度
  doi_engine.py      标题 → DOI（Crossref + 证据校验）

  preprints.py       ChemRxiv 预印本查找（标题/DOI 都可能不同）

  sources.py         开放获取来源聚合与缓存
  elsevier.py        Elsevier 官方接口
  wiley.py           Wiley TDM 接口
  browser.py         浏览器通道（机构登录、Cloudflare、ResearchGate）
  carsi.py           机构登录入口
  journals.py        期刊追新
  labpage.py         课题组主页抓取
  classify.py        本地学科/主题判定（可选）
  topics.py          OpenAlex 主题批量查询
  web/               界面（原生 JS，无构建步骤）
  dist/              打包产物（不入库）
```
